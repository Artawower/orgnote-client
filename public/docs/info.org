* [#A] OrgNote
[[https://github.com/Artawower/orgnote][OrgNote]] is a knowledge base built around [[https://www.orgroam.com/][Org-roam]], a GNU Emacs package for managing and linking notes.
/The current version is a prototype: it may contain bugs and can be unstable. Please be patient./

* [#B] Manifesto
The main idea of the project is to provide a full-featured Org-roam experience across desktop, mobile, and web (+PWA).

- The project should be free for everyone /except for some premium features that require hardware resources/.
- This is an open-source project: anyone can contribute and inspect how it works internally.
- The project should be community-oriented. If you have ideas, please share them.
  /Patrons can vote on feature priorities./
- The project should be free (including premium features) for open-source developers.
  /It’s hard to share with everyone, but I’ll try./
- It does not collect personal data and has no trackers.

* [#C] Limitations
*Make sure you back up your data.*

- There is currently no support for [[https://en.wikipedia.org/wiki/Conflict-free_replicated_data_type][CRDT]]. This means that if you use synchronization via =orgnote-cli=, you may lose some data.
  (It should automatically create backups if you use it in Emacs with [[https://github.com/Artawower/web-roam.el][orgnote.el]].)
- There are no migrations yet. I’m focusing on implementing the core features first.
  This means that if you make changes to the program, you may lose your data.
- I built the AST from scratch, and not all org-mode constructs are supported yet. The parser may also be missing some rules.
  If you encounter bugs, please report them via GitHub issues: [[https://github.com/Artawower/orgnote/issues][orgnote/issues]].
- The design is not final. I’m not a designer, so I’d be glad if someone could help 😊
- The iOS version is not published yet. I will publish it when we raise enough money for Apple Developer Program fees via [[https://www.patreon.com/artawower][Patreon]] (~$120/year).
  /You can freely use the *PWA* version on Apple devices right now./

* [#D] Plans
I have many ideas for integrating org-mode into a mobile app. Some require significant time and resources; others are longer-term plans.
The ideal app should include:

- Programmable configuration
- Linking and executing =src= code blocks
- Extension support
- CRDT support for seamless synchronization
- Full support for org-mode constructs
- Mobile notifications for your agenda
- Integration with third-party tools
